# EGFRpred

A standalone machine learning prediction tool for identifying Epidermal Growth Factor Receptor (EGFR) inhibitors using molecular fingerprints. 

`EGFRpred` utilizes a Random Forest classifier trained on 49 selected molecular fingerprints to predict whether a query molecule (provided in SMILES format) exhibits Anti-EGFR activity. It integrates **PaDEL-Descriptor** to calculate 1D/2D fingerprints on the fly before passing them through the classification pipeline.

---

## ⚠️ Crucial Environment Requirements (Legacy Run)

This repository is built for **Python 2.7** and relies on a legacy compiled model. To run this model successfully without Cython compiled constructor errors (such as `TypeError: __cinit__() takes exactly 6 positional arguments`), you must run it in a matching legacy environment.

## ⚠️ Important Environment Notice

This repository is currently built for **Python 2.7** and relies on legacy serialization (`cPickle`). To use this model without errors, ensure you are running a Python 2.7 environment with the compatible versions of `scikit-learn` and `numpy`.
